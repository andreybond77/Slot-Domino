# 🎰 Слот-домино (Slot Domino)

Браузерный слот-автомат на 3 барабанах с костяшками домино. Крутите, собирайте линии, используйте блокировки и перевороты, чтобы увеличить выигрыш.

**[🎮 Играть в демо](https://andreybond77.github.io/slot-domino/)** · **[📂 Исходный код](https://github.com/andreybond77/slot-domino)**

---

## ✨ Возможности

- **5 линий выплат:**
  - 💎 Три разных дубля → ×5
  - 🔷 Дубль в центре → ×4
  - 🔶 Дубли по краям → ×4
  - 🎉 Линия из 3 → ×3
  - ✨ Линия из 2 → ×2
- **Бонусная механика:**
  - 🔒 Блокировка барабана (2 за раунд, 5 💰) — барабан не крутится.
  - 🔄 Переворот костяшки — меняет `top` и `bot`.
  - 🔄 Пересчёт — одноразовый пересчёт выигрыша после изменения костяшек.
- **Защита от абуза:** `paidLine` и `paidLockedPair` не дают дважды оплатить одну и ту же линию.
- **Анимация и звук:**
  - Частицы на Canvas (конфетти, искры).
  - Вспышка экрана и тряска автомата при джекпоте.
  - Web Audio API: синтез звуков, включая «голосовые» эффекты через bandpass-фильтры.
- **UI/UX:** Анимированный счётчик баланса, быстрые ставки, адаптивность под мобильные.

## 🛠 Технологии

| Слой | Что использовано |
|------|------------------|
| Логика | Чистый JavaScript (ES6+) |
| Рендеринг | DOM (CSS Grid для костяшек) |
| Эффекты | Canvas 2D (частицы), CSS-анимации |
| Звук | Web Audio API (осцилляторы, фильтры) |
| Хранение | localStorage (настройки звука) |

**Без зависимостей.** Никаких фреймворков и сборщиков.
